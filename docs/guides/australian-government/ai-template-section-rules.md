# AI-009 — Template Section Rules (Mandatory vs Optional + Minimum Evidence)

This document defines minimum section requirements for AU AI artifacts.

## 1. au-ai-governance-assessment-template

| Section | Rule | Minimum evidence |
|---|---|---|
| In-scope determination | Mandatory | Appendix C criterion selection + rationale |
| Governance accountability | Mandatory | Named AO/AUCO and governance body |
| Mandatory conformance matrix | Mandatory | Status for each policy obligation + evidence link |
| Technical standard adoption plan | Mandatory when AI is developed/deployed by agency; otherwise conditional | Lifecycle applicability and control rationale |
| Legal/regulatory interface | Mandatory | Privacy/admin law/security notes |
| Action plan | Mandatory for any Partial/Not met control | Owner + due date |

## 2. au-ai-use-case-register-template

| Section | Rule | Minimum evidence |
|---|---|---|
| Minimum fields row set | Mandatory | All fields populated for each in-scope use case |
| High-risk addendum fields | Mandatory when inherent risk = high | Last/next review dates |
| Submission checklist | Mandatory | DTA submission date/path evidence |

## 3. au-ai-transparency-statement-template

| Section | Rule | Minimum evidence |
|---|---|---|
| Mandatory content set | Mandatory | All 7 required content elements |
| Plain-language quality | Mandatory | Public-facing readability check |
| Publication/review controls | Mandatory | URL + review trigger definitions |

## 4. au-ai-impact-assessment-template

| Section | Rule | Minimum evidence |
|---|---|---|
| Sections 1-12 | Mandatory for in-scope use cases | Completed fields consistent with DTA AIA structure |
| Risk rating tables | Mandatory | Consequence, likelihood, rationale, overall rating |
| Residual risk and treatments | Mandatory | Treatment owner/date/status |
| Governance review block | Mandatory for high-risk | Board/senior executive outcome + DTA reporting status |
| Re-validation triggers | Mandatory | Material change triggers + date cadence |

## 5. au-ai-governance-checklist-template

| Section | Rule | Minimum evidence |
|---|---|---|
| Gate A–E | Mandatory | Met/Partial/Not met status + evidence references |
| Exceptions/source gaps | Mandatory when uncertainty exists | SOURCE_GAP/TODO entries with owner/date |

## 6. jsp-936-template (AU defence pathway)

| Section | Rule | Minimum evidence |
|---|---|---|
| Public-source context | Mandatory | Cited AU public source anchors |
| Internal-policy gaps | Mandatory | Explicit SOURCE_GAP records |
| UK legacy handling | Mandatory | Reference legacy-uk path only when explicitly requested |

## 7. Evidence quality requirements

- Evidence must cite official AU policy corpus anchors.
- Evidence links must be specific enough to re-check (document + section/line reference).
- Unknown or non-public obligations must be marked `SOURCE_GAP` or `TODO`, never inferred.
